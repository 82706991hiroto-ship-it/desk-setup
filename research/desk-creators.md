# デスク発信者の調査と「あったら便利な機能」

調査日: 2026-09-29

デスクツアー・デスクセットアップを発信している人の記事や投稿を実際に開いて読み、何をどう書いているか、どこで手間がかかっていそうかを記録しました。その上で、発信者の立場から見て「デスク構成ビルダー」にあると便利な機能を考え、サーバーなし・無料のまま作れるかと手間の大きさを添えています。

## 読み方

- **事実**: 記事やページに書いてあったこと、ページ上で確認できたこと（日付・数・書き方など）。
- **推測**: 事実から私が考えたこと。発信者本人が言っているわけではありません。
- 機材の数は、記事の見出しや一覧を数えたおおよその数です。
- 出典は各節と最後の「出典一覧」に URL を残しています。

## 先に結論

1. **価格の書き方が発信者ごとにばらばら**で、しかも手間がかかっている。書かない人、ブログの商品ボックスが自動で出す「◯月◯日時点の参考価格」に任せる人、手で表を作って合計を出す人に分かれる。手で合計を出す人は「通常価格とセール価格」「合計に入れない番外品」「1日あたりの金額」など、今のツールの合計より一段細かいことをしている。
2. **購入リンクは Amazon・楽天・Yahoo の3〜4ボタン**がほぼ標準（WordPress なら「ポチップ」「Rinker」、note なら記事内のリンクカード）。一覧だけを別に置く人もいる（Amazon のリスト）。今のツールには購入リンクの欄がない。
3. **「前の構成からどう変わったか」を書く人が多い**。年ごとの変遷を1本にまとめる人（8年分・11時期）、「2023年版から変えたもの・変えなかったもの」を書く人、半年ごとに更新する人がいる。差分は毎回手で書いている。
4. **接続まわりは今のツールの強みと重なる**。USB-C 1本で映像と給電、ドックを Mac につないだら思った画面数にならない、Mac と Windows の切り替え（KVM）、5K2K を Mac で使うと文字が小さすぎる、などが実際に記事に書かれている。接続の図は手作りの画像で載せている人がいる。
5. **読者からの質問は記事にはあまり書かれない**。確認できたのは「ペン立てはどこのですか？」と聞かれるという記述と、発信者の側から「おすすめがあれば教えて」と聞いている記述くらい。X の返信や YouTube のコメントは今回読めていない（最後の「読めなかったもの」を参照）。

これをもとにした機能案のうち、手間が小さく効果が大きそうなのは次の5つです（詳しくは「3. あったら便利な機能」）。

- 機材ごとの購入リンク欄と、ブログ・YouTube 概要欄・note にそのまま貼れるテキストの書き出し
- 価格に「購入価格／参考価格」「いつの価格か」「合計に入れない」を持たせる
- 今の接続から、接続図（配線図）を画像で書き出す
- 構成を保存しておき、前の構成との差分（追加・入れ替え・継続）を出す
- 写真への書き込みに「番号だけ」の表示を足して、下に番号つき一覧を付ける

## 3. あったら便利な機能

### 手間の目安

- **小**: 今の `index.html` の仕組みの延長で済む。数十〜百数十行くらい。
- **中**: 新しい画面や描画が要る。数百行くらい。カタログに少しデータを足す。
- **大**: データの形（共有 URL の形式を含む）を変える、またはカタログのデータを大きく増やす必要がある。

「サーバーなしで作れるか」は、○＝作れる、△＝一部なら作れる（制限つき）、✕＝サーバーか外部サービスが要る、です。

### 3-1. すぐ役立ちそうなもの

| # | 機能 | 根拠（誰の何） | サーバーなしで | 手間 | メモ |
|---|---|---|---|---|---|
| 1 | **機材ごとの購入リンク欄**（URL と店名。複数可） | ほぼ全員が Amazon・楽天・Yahoo・直販のボタンを付けている。Amazon 以外の店も多い（まち、bingo+） | ○ | 小〜中 | 共有 URL に URL を入れると長くなる。短いショップ名＋商品 ID だけ持つなど工夫が要る |

|---|---|---|---|---|---|

|---|---|---|---|---|---|
| 21 | **写真に番号だけを書き、下に番号つき一覧を付ける** | りんこ（約45点）やツヨシ（約80点）のように点数が多いと、名前と価格をすべて写真に書くのは難しい | ○ | 中 | 今の書き込み機能の表示方式を1つ増やす形 |

### 3-5. サーバーがないと難しいもの

| 機能 | 理由 | 代わりにできること |
|---|---|---|
| 価格の自動取得・自動更新 | ブラウザから通販サイトのページは読めない（CORS）。Amazon の商品 API は秘密の鍵が要るのでサーバーが必要 | 価格の「日付」を持って、古い価格に印を付ける（#4） |
| 写真ごと URL で共有 | 写真は大きすぎて URL に入らない | 画像の書き出し（今ある）、HTML ファイルの保存（#23） |
| よく使われている機材の集計（README の「これから」にある） | みんなの構成を集める場所が要る | 公開された構成を手で集めて JSON にしてリポジトリに置く（更新は手作業） |
| 読者のコメント・「これどこの？」への質問受付 | 書き込みを保存する場所が要る | メモ欄（#9）で先に答えておく |
| リンクのクリック数 | 数えるにはサーバーが要る | なし（アソシエイト側の管理画面で見てもらう） |

### 3-6. 優先順位の案

「多くの発信者に効く」「手間が小さい」「今のツールの強みを伸ばす」で並べると次の順です。

1. #1 購入リンク欄 ＋ #2 記事用の一覧の書き出し ＋ #3 自分のタグ（ほぼ全員に効く。書き出しは Kazu のようなずれも防ぐ）
2. #4 価格の種類と日付 ＋ #5 合計に入れない印（手作り価格表の代わりになる）
3. #10 接続図の書き出し（ほかのサービスにない。接続データはもうある）
4. #17 構成の保存 ＋ #18 差分（変遷記事の手間が減る）
5. #12 ドックの Mac 制限 ＋ #13 Mac の文字の大きさ（実際に困った話が記事にある）
6. #21 写真の番号表示

## 4. 似たサービス

### 4-1. Desk Setup Builder（desksetupbuilder.com）

出典: https://www.desksetupbuilder.com/ 、https://www.desksetupbuilder.com/guides/clean-minimal-wfh 、https://www.desksetupbuilder.com/setup/w6ssp6n 、https://www.desksetupbuilder.com/builder 、https://www.desksetupbuilder.com/affiliate-disclosure

**事実**
- 3つの機能: 写真つきで構成を載せる「Setup Builder」、3D でデスクを組む「3D Setup Designer」、構成を見て回る「Explore」。トップページに「30+ setups」「210+ 3D designs」。
- 構成のページは表（Category／Product／Retailer／Availability／Price）。ガイド（「Clean Minimal WFH Setup」など）には「Clone」ボタンと「See it in 3D」。
- 構成ページに「Spot a product? Help identify it」（写真の中の製品を見た人が特定する）、コメント欄（ログインが必要）。
- 3D デザイナーは「No account needed to start」。保存にはログインが必要。
- 製品カタログに価格（ドル）と「Add to setup」。同じ製品が価格違いで何度も並んでいる箇所がある（Razer Kiyo V2 X が3件）。
- Amazon アソシエイトに参加していると明記。
- 接続・ポート・給電のチェックは見当たらない。

### 4-2. Workspaces（workspaces.xyz）

出典: https://workspaces.xyz/gear/ 、https://workspaces.xyz/about 、https://workspaces.xyz/submit 、https://workspaces.xyz/setups

**事実**
- 2020年4月開始のニュースレター兼アーカイブ。毎週土曜に1人のデスクを紹介。購読者 21,000人以上、紹介は500件以上（一覧ページでは「544 interviews」、Gear ページでは「546 Interviews」）。
- 1回の内容は「写真、短い自己紹介、リンクつきの機材一覧、4つの質問」。
- Gear ページは全インタビューに出てきた製品を「何件の構成に出てくるか」で並べたもの（3,690製品、うち 2,032 に購入リンク、22カテゴリ）。上位は MacBook Pro（330件）、Apple Magic Keyboard（133件）など。上位40品の PDF「Gear Report」を配布。
- 同じ製品が別名で並んでいる（「Yeti Blue」「Yeti Blue mic」「Yeti mic for audio」、「Yamaha HS5 monitors」「Yamaha HS5 Studio Monitors」など）。
- 応募は「全体が写った写真1枚でよい」。選ばれたら運営が機材一覧と質問の答えを集める。掲載は無料で、お金を受け取っての掲載はしない。アフィリエイトとスポンサー枠で運営。

**推測**
- 「何件の構成に出てくるか」の集計は、README の「よく使われている機材を集計する」と同じ発想。ただし集めた名前の表記ゆれをそろえる作業が大変そう（実際にそろっていない）。今のツールのカタログのように、最初から ID で選ばせる形は集計に向いている。

### 4-3. Kit.co（終了）と代わりのサービス

出典: https://kit.co/ 、https://makermanifest.co/blog/alternatives-to-kit-co

**事実**
- kit.co は「Service discontinued · May 11, 2026」「Kit.co has closed.」と表示されている。
- MakerManifest の記事（MakerManifest 自身が書いた比較なので、自社を一番に推している）によると、代わりの候補は次のとおり:
  - **MakerManifest**: URL から製品情報を自動取得、Amazon のタグを自動で付ける、短縮リンク、YouTube 概要欄向けの書き出し（1クリックでコピー）、kit.co の CSV の読み込み、クリック数などの分析。
  - **Linktree**: リンク集。カテゴリ分けや Amazon タグの管理はない。商品の見せ方（Commerce Links）は有料。
  - **Beacons.ai**: 「Store」ブロックで商品リンクを置ける。デジタル商品の販売などもできる。
  - **Amazon インフルエンサーのストアフロント**: Amazon の商品だけ。プログラムへの参加審査がある。
  - **Geniuslink**: 国ごとに Amazon のリンク先を振り分ける。一覧ページはない。
- 日本の発信者では、Amazon のショップページ・リスト（えふぃる、Fuyuna）や、記事内の一覧（りんこ）が同じ役割を担っている。

**推測**
- kit.co がなくなったことで「機材一覧を1か所にまとめてリンクを貼る場所」を探している人がいる。ただ、MakerManifest などはアカウント登録と自社サーバーが前提。
- このツールがそこに近づくなら、「一覧ページを持つ」より「一覧を作って、好きな場所（ブログ・概要欄・note）に貼る」方が、サーバーなしの方針に合う。kit.co の CSV の読み込みは、今の「一覧の貼り付け」機能の延長で作れる（小）。

## 5. 読めなかったもの・限界

- **YouTube の概要欄**: 動画ページを開くと YouTube のボット確認の画面になり、概要欄を読めなかった。動画タイトルは検索結果で確認した。
- **X の返信・引用**: 投稿本体（本文・日時・いいね数・返信数・画像枚数）は X の公開データで確認したが、返信の中身はログインが必要で読めなかった。そのため「よく聞かれている質問」は、記事の中に書かれていたもの（Fuyuna のペン立て）と、発信者の側からの問いかけ（bingo+、藤井翔太）に限られる。
- **tech-you のカテゴリページ**: 指定の URL を開くと記事が1本表示されたので、その記事を記録した。カテゴリ内のほかの記事は見ていない。
- **Workspaces の掲載件数**: ページによって 544 と 546 の2つの数字がある（更新のタイミングの差と思われる）。
- 機材の数は見出しや一覧から数えた目安で、数え方によって前後する。
