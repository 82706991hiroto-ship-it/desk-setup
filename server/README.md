# 利用者ランキングの集計サーバー

デスクレシピメーカーの「ツール利用者の人気」ランキングを集計する、Cloudflare Workers ＋ D1 のプログラムです。サイト本体（GitHub Pages）とは別に、Cloudflare に置きます。無料枠で動きます（1日10万リクエストまで）。

## 送られるもの・保存されるもの

- 利用者が「参加する」を押したときだけ送られます。
- 送るのは、構成リストの中の **カタログにある機材の ID** と、ブラウザが作った **ランダムな番号** だけです。自分で入力した名前・価格・メモ・購入先・写真・置き場所は送りません。
- IP アドレスは保存しません。送信回数の制限のために、IP と秘密の文字列（`SALT`）から作った置き換え値（ハッシュ）だけを保存します。
- 参加者が 10人未満のうちは、ランキングの中身を返しません。1人しか使っていない機材も出しません（誰が何を使っているか分からないようにするため）。
- 利用者はアプリの「参加をやめて、送った内容を消す」で、いつでも自分のデータを消せます。

## 公開先

https://desk-recipe-rank.82706991hiroto.workers.dev （2026年10月に公開。`/ranking` で動作確認済み）

アプリの `index.html` の `RANK_API` にこの URL を入れると、利用者ランキングのタブと参加の欄が出ます。利用者が増えるまでは空のままにしています。

## 公開の手順（Cloudflare の画面で行う）

画面の名前は変わることがあります。見つからないときは近い名前のメニューを探してください。

1. **アカウントを作る**: https://dash.cloudflare.com/sign-up
2. **データベースを作る**: 左のメニューの「ストレージとデータベース」→「D1 SQL データベース」→「作成」。名前は `desk-recipe-rank`。
3. **表を作る**: 作ったデータベースを開き、「コンソール」に [`schema.sql`](schema.sql) の中身（1行）を貼り付けて実行。続けて `/tables` を実行し、`clients` と `picks` が出れば完了。
   - `clients`: 参加したブラウザ（ランダムな ID）。`ip_hash` は送信回数の制限にだけ使い、IP そのものは保存しない
   - `picks`: 参加者ごとの、カタログにある機材の ID
   - コンソールは改行を消すので、`--` のコメントを入れると命令まで消えてしまう。schema.sql にはコメントを書かないこと
4. **Worker を作る**: 左のメニューの「Workers & Pages」→「作成」→「Worker を作成」。名前は `desk-recipe-rank` にして「デプロイ」。
5. **コードを入れる**: 作った Worker の「コードを編集」を開き、中身を全部消して [`worker.js`](worker.js) の中身を貼り付け、「デプロイ」。
6. **データベースをつなぐ**: Worker の「設定」→「バインディング」→「追加」→「D1 データベース」。変数名は **`DB`**、データベースは `desk-recipe-rank`。
7. **秘密の文字列を入れる**: Worker の「設定」→「変数とシークレット」→「追加」。種類は「シークレット」、名前は **`SALT`**、値は長くてランダムな文字列（パスワード生成ツールで作った 32文字以上など）。この値は誰にも教えないでください。
8. **URL を確認する**: Worker の画面に出ている `https://desk-recipe-rank.〇〇.workers.dev` をコピー。ブラウザで末尾に `/ranking` を付けて開き、`{"total":0,"min":10,"items":[]}` のような表示が出れば動いています。
9. この URL をアプリの `index.html` の `RANK_API` に入れると、ランキングに参加できるようになります。

## 動作の確認（手元）

`worker.js` はほかのファイルを使わない1ファイルです。受け付けるのは `https://82706991hiroto-ship-it.github.io` からの送信だけです（手元で試すときは、Worker の変数 `DEV_ORIGIN` に `http://localhost:8766` などを入れます）。

| 呼び出し | 内容 |
|---|---|
| `GET /ranking` | `{ total, min, items: [[機材ID, 人数], ...] }`。5分キャッシュ |
| `POST /submit` | `{ client, items }` を送る。同じ `client` は上書き |
| `DELETE /submit` | `{ client }` の送った内容を消す |

同じ回線から1日に参加できるブラウザは5つまでです。
