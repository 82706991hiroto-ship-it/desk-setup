# デスクレシピメーカー（DESK / RECIPE MAKER）

機材を並べて、写真に機材名と価格を書き込んで「#デスクレシピ」の画像をつくるツールです。合計金額・カテゴリ別の内訳や、モニターの映り方・ポート数・給電の接続チェックも出せます。構成はURLに入るので、そのまま X で共有できます。

https://82706991hiroto-ship-it.github.io/desk-setup/

## できること

- **画面の構成**: タブで「構成」「配線・3D」「チェック」「共有」「写真」に分かれています。「配線・3D」は机の配置・3D・つながり図をページの中に出し、全画面ボタンで画面いっぱいにできます。PC では「構成」の横に合計と接続チェックが並び、スマホでは「チェック」が別のタブになります（問題・注意の数がタブに出ます）。スマホの「構成」では、画面の下に合計とチェックの結果、「配線・3D」「チェック」へのボタンが出ます。機材リストは「詳しく」と「コンパクト」（1行ずつ、タップで開く。スマホでは最初からコンパクト）を切り替えられます。ランキングは「機材を追加」の「人気の機材」から開きます
- **機材リスト**: カタログから検索して追加、またはカタログにない機材を名前だけで追加。カタログにない機材は、カタログの似た機材を「元にする」と仕様と大きさを引き継いで名前だけ変えられます。PC・ドック・充電器はポート数・映像出力・給電W数、周辺機器はつなぎ方（Bluetooth / レシーバー / USB-C / USB-A）を「スペックを編集」で実物に合わせられます
- **合計金額**: カテゴリ別の内訳つき
- **買う予定**: 機材ごとに「買う予定」にできます。合計は買った後の金額になり、「今の構成 ＋ 買う予定」の内訳が出ます。接続チェックは買った後の構成で行い、配置図と 3D では予定の機材を透かして描くので、買う前に置き場所や配線を確かめられます。ランキングから追加した機材は「買う予定」で入り、利用者ランキングには送りません。価格ごとに「購入時／参考価格」と「いつの価格か」を持てて、番外・提供品・会社支給は合計から外せます
- **購入先リンクとメモ**: 機材ごとに複数の店の URL と、「どこで・いつ買ったか」のメモを残せます
- **記事用の書き出し**: 一覧をマークダウン・HTML の表・テキスト（YouTube 概要欄や X 向け）で書き出してコピーできます。価格・購入先・メモ・合計・「PR」表示・Amazon アソシエイトの表示文を入れるか選べます
- **接続チェック**
  - 外部ディスプレイの台数（例: MacBook Air M2 は1台まで、M3 は蓋を閉じると2台）
  - モニターの映り方（解像度×リフレッシュレートに対して、HDMI / DP / USB-C の帯域とPC側の出力上限が足りるか。ハブ経由なら上流で頭打ち）
  - ポート数（Thunderbolt / USB-C / USB-A / HDMI / DP が足りるか）
  - 給電（USB-C 給電モニターやドックのW数が、PCの推奨W数を満たすか）
  - 充電器の合計出力
  - モニターの USB ハブが今の接続で使えるか
  - Mac で USB-C ハブ（Thunderbolt ではないもの）に2台つないでいないか（Mac は MST 非対応のためミラーになる）
- **ランキング**: 「人気の機材を見る」で、デスク発信者がよく使っている機材（公開されているデスク紹介の調査から）と、このツールの利用者に人気の機材を見られます。利用者ランキングは、参加を選んだ人の「カタログにある機材の種類」だけを集計します（集計サーバーは [`server/`](server/)）
- **自動の接続先**: 機材を追加すると、空いているポートの中から、モニターは出せるリフレッシュレートが高いつなぎ方を選びます。同じならドック・ハブ経由にして PC のポートを空けておきます
- **モニターアーム**: 機材リストに「アーム・スタンド」のアーム（エルゴトロン LX など）を足すと、まだアームのないモニターに自動で付きます（名前に「デュアル」があれば2台）。どのモニターに付けるかはアームのカードで選べます。3D では天板の奥にクランプした支柱と関節のある腕で描き、2台を支えるアームは間に支柱1本です。アームのモニターは奥の端から少し手前に浮かせて置き、ケーブルは支柱に沿わせます。3D でモニターを選ぶと「縦にする／横にする」で向きを切り替えられ、画面が回って見えます（アームのモニターは画面の真ん中を軸に回します）。3D でアームのモニターを選ぶと、腕が届く範囲が天板に半円で出て、ドラッグするとその範囲の中で腕が曲がりながら付いてきます。▲▼で高さを 3cm ずつ変えられ、「動かしてみる」で手前に引き出す・左右に振る・戻す動きを数秒で見られます。アームの機材がなくても、モニターの「モニターアーム」で同じ形にできます
- **ドック**: ドックのカードで置き場所（机の下＝天板の裏に貼る／机の上／床）を選べます。自動では Thunderbolt ドックは机の下、USB-C ハブは机の上です。机の下のドックは、配置図では点線の輪郭、3D では天板ごしに輪郭が透けて見え、「下から」の視点で机の裏を見上げられます。机の上と机の下・床をつなぐケーブルは天板の奥の端から下ろして描きます。ドックを後から足したときは、カードの「今の機材をドック経由につなぎ直す」で、PC に直接つないでいる機材をまとめてドックにつなぎ替えられます（モニターはドック経由だと Hz が下がる・ミラーになる場合、ポートが足りない場合はそのまま）
- **配線図**: 「机の配置」では、天板の大きさを入れて、真上から見た机に機材をドラッグで置けます。上が奥（壁側）、下が手前（座る側）で、機材は種類ごとの形（モニターは画面の帯とスタンドの台座、キーボードはキーの並び、マウスは楕円など）で描きます。有線のケーブルは、機材からつなぎ先へ1本ずつ「まっすぐ」（ゆるく曲げた線）で描き、線の両端に点、つなぎ先の側にポート名（HDMI・USB-C・TB など）の札を付けます。「線」を「机の奥を通す」にすると、机の奥の端に沿った通り道を通した描き方になります。ワイヤレスの機材には BT・無線の印を付けます。PC ではマウスを乗せるだけで、スマホではタップで、その機材のつなぎ先とつながっている機材だけが濃く出て、ケーブル名も出ます（ほかは薄く）。図の下には、番号・名前・何に何でつながっているかの一覧が出て、一覧をタップしても選べます。機材を選ぶと、図の下に「ポートの絵」が出ます。PC・ドック・モニターなどはポート（Thunderbolt・USB-C・USB-A・HDMI・DisplayPort）ごとに何が刺さっているか・空いているかが分かり、モニターや周辺機器はつなげる先の機材のポートが並ぶので、空いているポート（緑の枠）をタップするとそこにつなぎ替えられます（ケーブルの種類が選べるときは、ケーブルを選んでから）。縮小して見ているとき（スマホなど）は、図の中は名前の代わりに番号です。3D と同じく、タップ（クリック）で選ぶと矢印ボタン・矢印キーで 1cm ずつ動かせ、2本指（ホイール）で拡大、何もない所のドラッグで見る場所を動かせます。縮小して見ているときは文字を大きく描くので、スマホでも読めます（スマホでは画面いっぱいに表示）。ケーブルは置いた場所に合わせて自動で引かれ（つなぐ相手は各機材の「接続先」）、映像・USB・給電・ワイヤレスで色分けされます（画面では流れるアニメーション付き）。「3D」では、机の配置をそのまま立体にして見られます。機材をドラッグすると机の上で動かせて（つかんだ高さで動くので指とずれにくく、天板の端では少し粘ります。大きくはみ出すと床に置けます。スマホでは指の動きの 6 割だけ動きます）、何もない所のドラッグで回転、ホイールやピンチで拡大します。タップ（クリック）で機材を選ぶと光る枠が付き、矢印ボタンや矢印キーで 2cm ずつ動かせます。スマホでは、選んだあとは画面のどこをなぞってもその機材が動き、2本指で回転・拡大します（指の近くの機材も拾います）。「斜め・正面・真上・下から」の視点切り替えと拡大・縮小ボタンがあり、スマホでは 3D を画面いっぱいに表示します。置き場所は「机の配置」と共通です（three.js を 3D を開いたときだけ読み込みます）。機材の大きさは、各機材の「大きさ・色（配置図・3D）」で幅・奥行・高さ（cm）を入れられます。3D の色（白・黒・シルバー。名前に「ホワイト」などがあれば自動で白）と、モニターの置き方（縦置き・曲面・モニターアーム）もここで選べます。空欄のときは、カタログにある機材は実寸、それ以外は名前（27インチ、14" など）と種類からの目安を使います。「つながり図」では、PC・ドック・モニター・周辺機器のつながりを左から右へ並べます。どちらも画像で保存でき、ケーブルの種類ごとの本数や PC に直接つながるケーブルの本数も出ます
- **記録と比較**: 今の構成を日付つきで記録しておき、前の記録との差分（追加・入れ替え・手放した・継続）と合計の変化を出せます。差分は記事用にマークダウンでコピーでき、記録ごとファイルに保存・読み込みもできます
- **共有**: 構成を圧縮してURLの `#d=` に入れるので、サーバーは不要です。X への投稿と、ポストに添付する画像の書き出しもできます

### 購入先リンクの扱い

Amazon アソシエイトなどのリンクは、登録した自分のサイトやアカウントにだけ貼る決まりがあります。そのため購入先リンクは共有リンクには入れず、端末の中にだけ保存して、書き出しで自分の記事に貼る形にしています。リンクはツール側で書き換えたり短縮したりしません。また、手で入力した価格を Amazon のリンクと並べると規約違反になるおそれがあるので、書き出しで Amazon のリンクを入れると価格は自動で外れ、並べたときは注意を出します（規約は各サービスの最新のものを確認してください）

- **写真に書き込む**: デスクの写真に、機材のブランド・名前・価格を矢印つきで書き込んで画像として保存できます。写真の上で機材をタップして名前を打てば、カタログや構成リストから候補が出てそのまま置けます。「Logicool MX Master 3S ¥16,500」のような一覧を貼り付けて、写真の上で順番にタップしていくこともできます（表計算ソフトやマークダウンの表にも対応）。ラベルと矢印の先はドラッグで動かせます。ラベルは、ほかのラベルと重ならず背景がすっきりした場所に自動で置かれます（「空いている場所に並べ直す」で全体をやり直すこともできます）。フォントは手書き風・ペン字・英字手書き・丸ゴシック・ゴシック・明朝・ポップの7種類から選べます。色は自動（背景の明るさで白か黒）/白/黒をラベルごとに選べ、大きさも変えられます

画面は暗い表示と明るい表示を切り替えられます（最初は端末の設定に合わせます）。

データはブラウザの localStorage にだけ保存します。写真もアップロードはせず、ブラウザの中だけで扱います。

## 構成

`index.html` 1ファイルで動きます。ビルドはありません。

- `CATALOG`: 機材のカタログとスペック（ポート、映像出力、給電W数など）
- カタログの仕様・寸法・参考価格の出典は `research/devices.md`（2026年9月調べ）。公式に記載がなく推定した値は、カタログの `note` に書いてあり、機材カードにも表示されます。カタログから追加すると `ref` の価格が「参考価格」として入ります
- `CATALOG_DIM`: カタログ機材の実寸 `[幅, 奥行, 高さ]`（cm）。ないものは `guessDims()` の目安、自分で入れた値（`it.dim`）があればそれを優先します
- `kindOf()`: 3D の形と自動配置に使う種類（ノート / タワー / スピーカー / マイク / Webカメラ など）
- `linkOptions()`: 機材ごとに選べる接続先（ホスト × ポート × ケーブル）
- `runChecks()`: 接続チェック本体
- `serialize()` / `deserialize()`: 共有URL・保存用の形式
- `drawPhoto()`: 写真へのラベルと矢印の描画（プレビューと書き出しで同じ処理）

### カタログに機材を足す

`CATALOG` に1行足します。カテゴリごとのスペックの書き方は、配列の直前にあるコメントを見てください。スペックは代表的な値で、あくまで目安です。大きさがわかるなら `CATALOG_DIM` にも足してください（モニターはスタンド込み、高さは一番低くしたときの机から上端まで。ノートPCの高さは閉じたときの厚さ）。
