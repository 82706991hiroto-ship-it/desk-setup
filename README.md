# デスクレシピメーカー（DESK / RECIPE MAKER）

機材を並べて、写真に機材名と価格を書き込んで「#デスクレシピ」の画像をつくるツールです。合計金額・カテゴリ別の内訳や、モニターの映り方・ポート数・給電の接続チェックも出せます。構成はURLに入るので、そのまま X で共有できます。

https://82706991hiroto-ship-it.github.io/desk-setup/

## できること

- **機材リスト**: カタログから検索して追加、またはカタログにない機材を名前だけで追加。カタログにない機材は、カタログの似た機材を「元にする」と仕様と大きさを引き継いで名前だけ変えられます。PC・ドック・充電器はポート数・映像出力・給電W数、周辺機器はつなぎ方（Bluetooth / レシーバー / USB-C / USB-A）を「スペックを編集」で実物に合わせられます
- **合計金額**: カテゴリ別の内訳つき。価格ごとに「購入時／参考価格」と「いつの価格か」を持てて、番外・提供品・会社支給は合計から外せます
- **購入先リンクとメモ**: 機材ごとに複数の店の URL と、「どこで・いつ買ったか」のメモを残せます
- **記事用の書き出し**: 一覧をマークダウン・HTML の表・テキスト（YouTube 概要欄や X 向け）で書き出してコピーできます。価格・購入先・メモ・合計・「PR」表示・Amazon アソシエイトの表示文を入れるか選べます
- **接続チェック**
  - 外部ディスプレイの台数（例: MacBook Air M2 は1台まで、M3 は蓋を閉じると2台）
  - モニターの映り方（解像度×リフレッシュレートに対して、HDMI / DP / USB-C の帯域とPC側の出力上限が足りるか。ハブ経由なら上流で頭打ち）
  - ポート数（Thunderbolt / USB-C / USB-A / HDMI / DP が足りるか）
  - 給電（USB-C 給電モニターやドックのW数が、PCの推奨W数を満たすか）
  - 充電器の合計出力
  - モニターの USB ハブが今の接続で使えるか
  - Mac で USB-C ハブ（Thunderbolt ではないもの）に2台つないでいないか（Mac は MST 非対応のためミラーになる）
- **自動の接続先**: 機材を追加すると、空いているポートの中から、モニターは出せるリフレッシュレートが高いつなぎ方を選びます。同じならドック・ハブ経由にして PC のポートを空けておきます
- **配線図**: 「机の配置」では、天板の大きさを入れて、真上から見た机に機材をドラッグで置けます。ケーブルは置いた場所に合わせて自動で引かれ、映像・USB・給電・ワイヤレスで色分けされます（画面では流れるアニメーション付き）。「3D」では、机の配置をそのまま立体にして見られます。機材をドラッグすると机の上で動かせて（天板の外まで動かすと床に置けます）、何もない所のドラッグで回転、ホイールやピンチで拡大します。タップ（クリック）で機材を選ぶと光る枠が付き、矢印ボタンや矢印キーで 2cm ずつ動かせます。スマホでは、選んだあとは画面のどこをなぞってもその機材が動き、2本指で回転・拡大します（指の近くの機材も拾います）。「斜め・正面・真上」の視点切り替えと拡大・縮小ボタンがあり、スマホでは 3D を画面いっぱいに表示します。置き場所は「机の配置」と共通です（three.js を 3D を開いたときだけ読み込みます）。機材の大きさは、各機材の「大きさ（配置図・3D）」で幅・奥行・高さ（cm）を入れられます。空欄のときは、カタログにある機材は実寸、それ以外は名前（27インチ、14" など）と種類からの目安を使います。「つながり図」では、PC・ドック・モニター・周辺機器のつながりを左から右へ並べます。どちらも画像で保存でき、ケーブルの種類ごとの本数や PC に直接つながるケーブルの本数も出ます
- **記録と比較**: 今の構成を日付つきで記録しておき、前の記録との差分（追加・入れ替え・手放した・継続）と合計の変化を出せます。差分は記事用にマークダウンでコピーでき、記録ごとファイルに保存・読み込みもできます
- **共有**: 構成を圧縮してURLの `#d=` に入れるので、サーバーは不要です。X への投稿と、ポストに添付する画像の書き出しもできます

### 購入先リンクの扱い

Amazon アソシエイトなどのリンクは、登録した自分のサイトやアカウントにだけ貼る決まりがあります。そのため購入先リンクは共有リンクには入れず、端末の中にだけ保存して、書き出しで自分の記事に貼る形にしています。リンクはツール側で書き換えたり短縮したりしません。また、手で入力した価格を Amazon のリンクと並べると規約違反になるおそれがあるので、書き出しで Amazon のリンクを入れると価格は自動で外れ、並べたときは注意を出します（規約は各サービスの最新のものを確認してください）

- **写真に書き込む**: デスクの写真に、機材のブランド・名前・価格を矢印つきで書き込んで画像として保存できます。写真の上で機材をタップして名前を打てば、カタログや構成リストから候補が出てそのまま置けます。「Logicool MX Master 3S ¥16,500」のような一覧を貼り付けて、写真の上で順番にタップしていくこともできます（表計算ソフトやマークダウンの表にも対応）。ラベルと矢印の先はドラッグで動かせます。ラベルは、ほかのラベルと重ならず背景がすっきりした場所に自動で置かれます（「空いている場所に並べ直す」で全体をやり直すこともできます）。フォントは手書き風・ペン字・英字手書き・丸ゴシック・ゴシック・明朝・ポップの7種類から選べます。色は自動（背景の明るさで白か黒）/白/黒をラベルごとに選べ、大きさも変えられます

画面は暗い表示と明るい表示を切り替えられます（最初は端末の設定に合わせます）。

データはブラウザの localStorage にだけ保存します。写真もアップロードはせず、ブラウザの中だけで扱います。

## 構成

`index.html` 1ファイルで動きます。ビルドはありません。

- `CATALOG`: 機材のカタログとスペック（ポート、映像出力、給電W数など）
- カタログの仕様・寸法・参考価格の出典は `research/devices.md`（2026年9月調べ）。公式に記載がなく推定した値は、カタログの `note` に書いてあり、機材カードにも表示されます。カタログから追加すると `ref` の価格が「参考価格」として入ります
- `CATALOG_DIM`: カタログ機材の実寸 `[幅, 奥行, 高さ]`（cm）。ないものは `guessDims()` の目安、自分で入れた値（`it.dim`）があればそれを優先します
- `kindOf()`: 3D の形と自動配置に使う種類（ノート / タワー / スピーカー / マイク / Webカメラ など）
- `linkOptions()`: 機材ごとに選べる接続先（ホスト × ポート × ケーブル）
- `runChecks()`: 接続チェック本体
- `serialize()` / `deserialize()`: 共有URL・保存用の形式
- `drawPhoto()`: 写真へのラベルと矢印の描画（プレビューと書き出しで同じ処理）

### カタログに機材を足す

`CATALOG` に1行足します。カテゴリごとのスペックの書き方は、配列の直前にあるコメントを見てください。スペックは代表的な値で、あくまで目安です。大きさがわかるなら `CATALOG_DIM` にも足してください（モニターはスタンド込み、高さは一番低くしたときの机から上端まで。ノートPCの高さは閉じたときの厚さ）。
